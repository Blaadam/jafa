# Installation

Jafa is a single binary written in Rust. It doesn't need Node.js or any other
runtime.

## Requirements

- [Rokit](https://github.com/rojo-rbx/rokit) available on your `PATH` (Jafa
  runs `rokit install` for you during `jafa init`, but Rokit itself must
  already be installed)
- Git

## Install a prebuilt binary

Download the archive for your platform from the
[latest release](https://github.com/blaadam/jafa/releases/latest)
(`x86_64-pc-windows-msvc`, `x86_64-unknown-linux-gnu`,
`x86_64-apple-darwin`, or `aarch64-apple-darwin`), extract it, and put the
`jafa` binary somewhere on your `PATH`. No Rust toolchain required.

## Install with Cargo

With [Rust](https://www.rust-lang.org/tools/install) installed:

```sh
cargo install --git https://github.com/blaadam/jafa jafa
```

This builds the latest `jafa` (including unreleased changes) and puts it in
Cargo's `bin` folder, which is normally already on your `PATH`.

## Install from source

```sh
git clone https://github.com/blaadam/jafa.git
cd jafa/tool
cargo install --path .
```

## Verify

```sh
jafa --version
jafa --help
```
